# ESP32 PWM DC Motor Controller

Controls a DC motor through an L293D H-bridge using ESP32 PWM. Motor speed ramps automatically, while a push button changes the motor direction.

## Key Features
- PWM-based motor speed control
- Automatic duty-cycle ramp
- H-bridge direction control
- Interrupt-driven direction changes
- Hardware timer for periodic speed updates

## Concepts Demonstrated
PWM, GPIO, interrupts, hardware timers, H-bridge motor control, and state management.

## Environment
ESP32 using the Arduino framework.
